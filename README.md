# 🔐 Digital Footprint Risk Analyzer  

An AI-powered web application that analyzes user digital behavior and predicts privacy risk levels using Machine Learning. The system provides real-time risk scores, explainable AI insights, and personalized privacy improvement recommendations.

---

## 📖 Project Overview  

In today’s digital world, users generate a large amount of online data through social media, applications, and browsing activity. This creates a digital footprint that can expose users to privacy risks such as data breaches, identity theft, and unauthorized tracking.

The Digital Footprint Risk Analyzer helps users understand their online behavior by:  
- Analyzing digital activity patterns  
- Predicting privacy risk levels  
- Explaining key risk factors  
- Suggesting security improvements  

---

## 🎯 Objectives  

- To analyze digital behavior data using Machine Learning  
- To predict privacy risk scores in real-time  
- To visualize important features affecting privacy risk  
- To provide actionable security recommendations  
- To deploy a user-friendly web-based dashboard  

---

## 🚀 Features  

✔ Real-time Privacy Risk Prediction  
✔ Risk Score Visualization (Gauge Meter)  
✔ Explainable AI (Feature Importance Analysis)  
✔ Interactive Web Dashboard  
✔ Personalized Privacy Recommendations  
✔ Live Deployment Support

## 🧠 Machine Learning Models Used  

The system trains and evaluates multiple ML models and automatically selects the best-performing one:

- Random Forest Classifier  
- Gradient Boosting Classifier  
- Logistic Regression  

The final model is selected based on accuracy and performance metrics.

## 📊 Dataset Information  

The dataset contains realistic digital behavior attributes including:

- Screen Time (hours/day)  
- Public Profile Status  
- Location Sharing Status  
- Two Factor Authentication  
- Password Strength Score  
- Social Media Platform Count  
- Public Posts Count  
- App Permission Count  
- Data Breach Exposure  
- Risk Label (Target Variable)  

The dataset is preprocessed and formatted for machine learning classification tasks.
